# 表格数据检查辅助 (Excel Table Checker)

基于 **Python 3.13** 与 **PyQt5** 开发的现代化桌面端自动化表格处理与数据核对辅助工具。

通过后台持续监听系统剪切板，自动捕获从 Excel / WPS / 网页中复制的表格数据，根据用户在低代码积木编辑器中配置的规则（尺寸前提、正则约束、网络请求、用户输入等），流水线式自动化执行后续数据处理，并将生成的新表格或文本以 Excel 原生格式自动写回剪切板。

---

## 核心功能与亮点

- **低代码积木式可视化编辑器 (Low-Code Block Programming)**：
  - 无需手写代码，拖拉拽式添加并排序各种处理动作。
  - 支持积木自由**上移 (▲)**、**下移 (▼)**、**一键复制 (克隆)** 与**删除**。
- **双向数据同步**：
  - 支持「低代码积木视图」与「JSON 源码视图」毫秒级双向同步。
  - 完美兼容**中文自然语义键名**（如 `"配置名称"`、`"触发该配置的前提"`、`"发网络请求"`）与**英文标准键名**。
- **后台持续化剪切板智能监控**：
  - 精准识别 Excel 原生表格格式（TSV），自动解析行列维度。
  - **1x1 表格完美兼容**：针对部分软件将 1x1 复制为纯文本的情况，工具自动将纯文本兼容视为 1x1 表格。
  - 内置防循环回环保护：程序写入剪切板的内容不会再次被触发。
- **前置触发过滤**：
  - **表格大小校验与模糊匹配 (可配置)**：
    - 精确匹配行数 × 列数，亦可自由勾选「模糊行数 (任意行)」、「模糊列数 (任意列)」或「同时模糊」。
    - **系统变量 `row` 与 `column`**：无论精确还是模糊匹配，引擎均自动建立全局系统变量 `row` 与 `column`（分别代表实际捕获的表格行数与列数），可供后续积木通过 `row`、`column` 或 `{{row}}`、`{{column}}` 直接读取。
  - **多重额外格式条件（可选，多条件 AND 联动）**：支持动态添加多个 `(行, 列)` 单元格正则匹配条件，所有条件通过逻辑与 (AND) 关系必须全部满足方可触发，每个条件均配备独立的可视化**实时正则测试器**。
- **丰富的动作积木库 (持续动态扩展)**：
  1. `🧩 提取单元格 (extract_cell)`：提取指定位置单元格内容，存储到上下文变量：
     - **支持变量与表达式传入行列数**：行号与列号既可输入数字常量，亦可直接传入变量名（如 `target_row`）或模板变量（如 `{{r}}`）。
     - **自动类型转换与非法拦截**：执行时自动将变量解析并转换为整数，若传入非数字值将明确报错并中止流程，保障计算安全。
  2. `🌐 发网络请求 (http_request)`：支持 GET/POST/PUT/DELETE，支持在 URL/Header/Body 模板化插入 `{{变量}}`，支持毫秒级超时控制，支持同步等待响应并根据 JSONPath 回调提取字段（如 `res.data[0]`）。
  3. `💬 用户输入 (user_input)`：弹出模态输入弹窗，由用户补充指定变量。
  4. `🔔 弹出提示框 (show_message)`：弹出提示窗口展示处理结果（支持 `{{变量}}` 插值）。
  5. `💬 弹出冒泡窗 (toast)`：轻量非模态浮动冒泡通知，支持 5 大配置参数：
     - **内容**：支持 `{{变量}}` 模板插值；若插值后内容为空则自动跳过展示。
     - **持续时间**：毫秒数（或秒数），控制冒泡自动淡出消失时长。
     - **是否阻塞**：勾选时流水线同步等待冒泡结束；不勾选则在后台异步展示不中断后续执行。
     - **显示的屏幕**：支持「所有屏幕」与「鼠标所在屏幕」。
     - **显示的位置**：支持「顶部居中」、「正中间」、「底部居中」、「持续跟随鼠标」（选择跟随鼠标时自动禁用屏幕选择并进行 40fps 平滑跟随）。
  6. `🔢 计算 (compute)`：图灵完备计算积木，将复杂的右值计算结果赋值给左值变量：
     - **字符串双引号转义字符深度解析**：计算表达式中的双引号（及单引号）字符串原生支持转义字符解析，包括 `\t`（制表符）、`\n`（换行）、`\r`（回车）、`\\`（反斜杠）、`\"`（双引号）、`\'`（单引号）等（例如 `strcat(col1, "\t", col2, "\n")`），计算产生的真实制表符与换行符可直接赋给左值变量存储。
     - **变量原生支持转义字符**：上下文变量完美支持存储包含 `\t`、`\n`、`\r` 等特殊字符的文本，在后续积木引用与 `{{变量}}` 模板插值中保持完整真实字符，不丢失、不破坏转义语义。
     - **三元运算符支持 (C-Style Ternary Operator)**：表达式右值支持 `条件 ? 满足的运算 : 不满足的运算`，支持条件、问号冒号分支内任意深度的嵌套与右结合运算，且内置短路惰性求值 (Lazy Evaluation，未选中分支不计算除零或不存在的变量)。
     - **算术与取模**：支持 `+`、`-`、`*`、`/`、`%`，自动将字符串转换为浮点/整型运算，转换失败直接中止流水线报错；默认最大保留 6 位非零小数。
     - **逻辑与比较**：支持 `&&`、`||`、`!`、`==`、`!=`、`<`、`<=`、`>`、`>=`，计算结果严格遵循非零即一（输出 `"1"` 或 `"0"`），无布尔字符串歧义。
     - **内置函数**：提供 `str(x)`、`substr(s, start, [len])`、`strcat(s1, s2, ...)`、`round(x, [n])`、`ceil(x)`、`floor(x)`，支持括号嵌套优先级。
     - **全局作用域与变量名规范**：所有变量运行于全局作用域；变量名严格遵循通用标识符规则，必须以下划线或字母开头，可包含大小写字母、数字及下划线 (`^[a-zA-Z_][a-zA-Z0-9_]*$`)。
  7. `🔀 如果 (if)`：图灵完备多层嵌套选择结构积木：
     - **多层任意嵌套与级联缩进**：支持多层嵌套 If/Else 结构，调度引擎采用分层作用域栈精确控制跳转与出栈；积木编辑器呈现 Scratch 风格彩色卡扣，缩进边距随嵌套深度比例递增 (`28 * 层级 px`) 并标注分支层级角标。
     - **纯粹语义的 Else 支持**：移除了繁琐的「包含else分支」复选框，默认提供 Else 积木数配置且默认为 0；Else 积木数为 0 时语义上即为不包含 Else 分支。
     - 深度兼容分支内部包含 `goto` 的跳转与循环场景。
  8. `🔂 跳转 (goto)`：图灵完备循环与无条件/条件跳转积木：
     - 输入条件表达式与目标步骤行号；当条件非零时直接将流程计数器跳转到目标行号，轻松构建 `while`、`for` 循环结构。
     - **双向快速跳转与非计数占位标记**：
       - **目标位置紧凑占位标记 (`GotoTargetMarkerWidget`)**：在 Goto 目标步骤上方自动插入超紧凑不占序号的占位积木，清晰显示是第几步的 Goto 跳转至此，点击即可一键滑至对应的 Goto 积木。
       - **Goto 积木一键跳转**：Goto 积木卡片右侧新增「🎯 跳转」按钮，点击立即将视口平滑滚动至目标步骤并高亮呈现。
     - 调度引擎内置最大步数（默认 10000 步）防死循环保护机制。
  9. `🛑 退出 (exit)`：直接终止积木，无需传入任何参数，执行后立即正常结束流水线流程，常与 `如果` 分支配合使用实现条件提前退出。
  10. `📋 写入剪切板 (write_clipboard)`：
     - **写入前智能转义解析**：写入系统剪切板时，自动对模板文本及变量中的转义字符进行转义解析（如 `\t` 转为真实制表符、`\n` 转为真实换行符、`\\` 转为反斜杠），彻底解决外部输入字面量 `\t`、`\n` 无法分列换行的问题。
     - **表格与文本双模式**：
       - `text`（纯文本模式）：以真实换行和制表符写入剪贴板，在记事本或编辑器中直接呈现清晰排版。
       - `table`（表格模式）：支持 CSV 逗号分割或 `\t` 分列文本，自动转换为 Excel 原生 TSV 格式 (`\r\n` 换行、`\t` 分列），在 Excel 中 Ctrl+V 粘贴直接自动分行分列入格。
  11. `📁 文件读写 (file_ops)`：扩展动作，支持本地文件读取、写入与追加。
- **全新积木拖拽排版与手势重构**：
  - 彻底移除传统「▲ 上移」与「▼ 下移」按钮，在积木卡片最左侧新增 **SVG 六点手柄 (`create_svg_drag_handle_button`)**。
  - **防抖与跟手**：8px 距离阈值防误触触发，拖拽时浮动半透明卡片预览与吸附光标平滑跟手；中间精准渲染蓝色定位插入线。
  - **拖拽至右侧滚动条快速定位**：将积木拖到右侧 VS Code 概览滚动条上方时，视口将按比例极速滚动，适合长流程步骤移动。
  - **拖拽至左侧安全删除**：将积木拖至左侧区域自动激活删除提示，松开后触发二次确认弹窗 (`QMessageBox`)，防止误删。
- **现代化紧凑积木卡片与 SVG 悬浮提示**：
  - 各动作卡片标题右侧集成矢量 SVG 感叹号按钮，移除卡片体内占位文案，鼠标悬浮即可查看参数提示，界面精简高效。
- **VS Code 风格透明概览滚动条 (VS Code Overview Scrollbar)**：
  - 深度美化积木区右侧竖直滚动条，采用现代亚克力半透明玻璃质感与无边框设计。
  - **动态视口与积木颜色映射**：
    - **当前可见页面**：在半透明毛玻璃滑块（带霓虹蓝边界指示线）内以高饱和度原色、发光边缘与清晰序号高亮展示。
    - **当前不可见页面**：在滑块外部区域以柔和半透明胶囊条呈现，直观透视视口上方及下方的积木分布。
    - **实时拖拽高亮指示器**：在拖拽积木调整顺序时，概览滚动条对应步骤胶囊条将实时呈现琥珀色发光边框与红色拖拽焦点光标，让用户对长流程移动位置了如指掌。
  - **全交互能力**：支持点击胶囊条直接快速定位至该积木、点击轨道跳转、拖拽滑块以及鼠标悬浮查看富文本步骤详情与可见性状态提示。
- **内置表格模拟测试器 (Clipboard Simulator)**：
  - 无需频繁切换外部 Excel 即可在工具内输入样例数据进行端到端全流程仿真。
  - 运行时变量检查器 (Variables Inspector) 实时展示每个变量的状态与最终剪切板产物。
- **配置热更新 / 热插拔**：
  - 监控 `configs/` 目录的修改与新增，自动检测文件变动并热重载，无需重启软件。

## 整体工作流程

```mermaid
flowchart TD
    A[用户在 Excel/软件中按下 Ctrl+C 复制] --> B[后台剪切板监控拦截数据]
    B --> C{检查表格尺寸是否与当前规则匹配?}
    C -- 否 (或普通文本非1x1) --> D[跳过此次复制]
    C -- 是 --> E{是否配置额外条件?}
    E -- 否 --> G[触发条件全部满足]
    E -- 是 --> F{指定单元格是否符合正则表达式?}
    F -- 否 --> D
    F -- 是 --> G
    G --> H[按照积木顺序逐步执行流水线动作]
    H --> I[提取单元格内容至 {{id}}]
    I --> J[发送 HTTP 网络请求 (同步等待返回)]
    J -- 超时或失败 --> K[终止流水线并弹窗报错]
    J -- 成功 --> L[按回调表达式提取返回字段至 {{newData}}]
    L --> M[弹出输入框获取用户输入 {{index}}]
    M --> N[弹出提示框告知用户结果]
    N --> O[将重组数据以表格格式写入剪切板]
    O --> P[用户可在 Excel 中直接 Ctrl+V 粘贴新表格]
```

## 配置文件规范 (示例配置1.json)

工具支持如下格式的规则定义，保存在 `configs/` 目录下：

```json
{
  "配置名称": "用户ID数据查询与格式化示例",
  "触发该配置的前提": {
    "表格大小": [1, 1],
    "额外条件": {
      "位置": [0, 0],
      "正则表达式": "[0-9]{3,}"
    }
  },
  "触发后的流程": [
    {
      "动作": "提取某一格",
      "操作位置": [0, 0],
      "暂存到的变量名": "id"
    },
    {
      "动作": "发网络请求",
      "方法": "POST",
      "url": "https://example.com/api/user/{{id}}",
      "header": {
        "Content-Type": "application/json"
      },
      "body": "{\"id\": \"{{id}}\"}",
      "timeout": 10000,
      "callback": {
        "newData": "res.data[0]"
      }
    },
    {
      "动作": "用户输入",
      "提示文本": "请输入要提取第几个",
      "变量名": "index"
    },
    {
      "动作": "弹出提示框",
      "内容": "新内容为{{newData}}"
    },
    {
      "动作": "写入剪切板",
      "type": "table",
      "data": "{{id}},{{newData}},{{index}}"
    }
  ],
  "启用状态": true
}
```

## 快速上手与运行

### 1. 环境准备
确保已安装 Python 3.11+ / 3.13：
```bash
pip install -r requirements.txt
```

### 2. 启动图形化客户端 (GUI)
```bash
python3 main.py
```
操作步骤：
1. 顶部下拉框选择或者点击「新建」配置规则。
2. 在「低代码积木编辑器」中直观调整触发尺寸、正则规则与积木动作。
3. 点击顶部绿色按钮「开启该规则后台监控」。
4. 切换到 Excel 或其他文本编辑器复制表格，工具将自动捕获并执行全套流程！

### 3. CLI 仿真运行 (无头模式 / 脚本调试)
可以在终端中直接模拟剪切板输入，无需开启图形界面：
```bash
python3 main.py --simulate "888" --config configs/示例配置1.json
```
运行线上可用真实测试样例：
```bash
python3 main.py --simulate "octocat" --config configs/github_user_lookup.json
```

### 4. 运行全套自动化测试
```bash
python3 -m pytest -v
```
全套自动化测试覆盖所有核心算子、模糊尺寸匹配、Goto 积木顺序排版、配置迁移工具与多线程安全机制。

### 5. 配置文件架构迁移与升级工具 (migrate_configs.py)
提供完全独立的零依赖脚本，每次发布新版本后运行该脚本，即可自动扫描、升级并验证所有配置文件符合最新框架定义：
```bash
# 升级 configs/ 目录下全部配置文件到最新框架架构
python3 migrate_configs.py

# 预检模式 (Dry-Run / Check-Only)，仅检测不写入文件
python3 migrate_configs.py --check-only

# 升级并在写入前自动创建 .bak 备份文件
python3 migrate_configs.py --backup

# 升级指定规则文件
python3 migrate_configs.py --file configs/my_custom_rule.json

# 键名语言规范化 (keep 保持原样 / chinese 规范为中文键 / english 规范为英文键)
python3 migrate_configs.py --lang chinese
```
